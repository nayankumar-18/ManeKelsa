# Mane-Kelsa Android App

Native Kotlin Android app for Project 20: a hyper-local work directory for domestic workers, gardeners, painters, electricians, and nearby residents.

## Features

- Kannada-first UI for semi-literate local users.
- Worker dashboard with clear large actions.
- Worker profile with skill chips, daily rate, location, rating, and call action.
- Availability switch with persisted offline-ready state.
- Nearby worker list sorted by distance/street.
- One-tap phone dial intent.
- Simple thumbs-up/star rating flow.

## Build

```powershell
gradle assembleDebug
```

The debug APK is generated at `app/build/outputs/apk/debug/app-debug.apk`.
